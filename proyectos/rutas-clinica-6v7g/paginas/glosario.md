| Término | Definición |
| --- | --- |
| Atributos críticos de calidad | Propiedades del producto (pureza, impurezas, estructura, estabilidad, actividad biológica) que deben mantenerse dentro de límites para asegurar su desempeño. |
| Bioequivalencia | Demostración de que dos productos producen exposiciones al principio activo (concentración y área bajo la curva) suficientemente similares. Aplica sobre todo a medicamentos de síntesis química. |
| Biosimilar | Producto biológico altamente similar a una referencia ya aprobada, autorizado mediante comparabilidad. En Colombia, por las rutas de comparabilidad o comparabilidad abreviada. |
| Buenas prácticas de elaboración | Requisitos de calidad para los servicios farmacéuticos que elaboran preparaciones magistrales. |
| Buenas prácticas de manufactura | Requisitos de calidad para la fabricación industrial de medicamentos. |
| Cambio de producto (switching) | Paso de un paciente de un producto a otro con el mismo principio activo, por decisión del médico. |
| Comparabilidad | Comparación escalonada (analítica, funcional, farmacocinética y, si se requiere, clínica) entre un biológico y su referencia. También se exige cuando el fabricante cambia su proceso de manufactura. |
| Extrapolación de indicaciones | Autorización de una indicación sin estudios clínicos propios en ella, con base en la totalidad de la evidencia obtenida en otra indicación. |
| Farmacovigilancia | Detección, evaluación y prevención de eventos adversos después de la comercialización. |
| Incertidumbre residual | Lo que queda sin resolver sobre el desempeño de un producto después de autorizado. |
| Inmunogenicidad | Capacidad de un producto de inducir una respuesta inmune, por ejemplo anticuerpos que reducen su efecto o causan reacciones. |
| Intercambiabilidad | Condición de poder usar un producto en lugar de otro con el mismo resultado clínico esperado. En Colombia no existe una designación explícita para biológicos. |
| M, MB y MBT | Códigos del registro sanitario: M para síntesis química; MB para medicamento biológico; MBT para medicamento biotecnológico. |
| Producto de referencia | El producto originador frente al cual se compara un genérico o un biosimilar. |
| Producto no originador | Producto de un fabricante distinto al innovador: genérico o biosimilar, según la ruta. |
| Reliance | Uso de evidencia o de evaluaciones previas como base de una autorización, con un puente de evidencia específica del producto. |
| Sustitución | Reemplazo de un producto por otro realizado por la farmacia o la institución, sin intervención del médico. |
| Trazabilidad | Capacidad de saber qué producto, de qué fabricante y de qué lote recibió cada paciente. |
